# Студия КП: фоновое сохранение и редактор в проекте

Дата: 08.10.2026. Сценарии проверены на локальном dev-сервере (3102), все `/api/**` перехвачены synthetic fixtures. Рабочая БД не изменялась.

## Проверено

- Vitest: 42 файла / 240 тестов PASS; production build и targeted ESLint PASS.
- Задержанный первый запрос: мгновенные предварительные карточки двух услуг, запрет повторного добавления, последовательная отправка с revision 4/5/6, максимум один запрос записи одновременно.
- Можно выбрать другой раздел и открыть/сохранить существующую услугу во время записи. Новая несохранённая форма переживает ответ предыдущего запроса; native Ctrl+Z в поле не отправляет серверную команду.
- Undo/redo после подтверждения очереди. Потерянный ответ после server commit: три ограниченных повтора с одним UUID; reload и явная проверка того же запроса не увеличивают revision повторно.
- 409 сохраняет отправленные поля в локальном журнале, не разрешает экспорт неподтверждённого состояния, оставляет просмотр клиентского вида. Загрузка серверной версии требует осознанного отказа от локальных изменений.
- Desktop 1920/1440 и mobile 390: нет горизонтального overflow. Мобильный документ заканчивается в пределах 40px после холста; фактически отступ ~12px.
- Из проекта открывается один общий полноэкранный редактор без смены URL и второго AppShell. Escape сначала закрывает инспектор, затем fullscreen. Клиентская print media скрывает проектный фон, внутренние расходы и controls. Перенос уведомляет проектный блок сметы о необходимости обновления.
- Нет page errors. Выравнивание empty state сметы проверено на проектном capture.
