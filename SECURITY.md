# Безопасность Wowstorg Webapp

Поддерживается текущая версия ветки `master`. Старые production deployments нельзя считать безопасными только потому, что они собираются.

## Сообщение об уязвимости

Свяжитесь с владельцем проекта приватно по уже известному каналу. Не создавайте публичный issue с персональными данными, рабочими URL с токенами, дампами, cookie, паролями или ключами. Наличие GitHub Private Vulnerability Reporting не предполагается без проверки настроек.

В сообщении нужны: компонент/версия, условия, минимальные шаги на тестовом аккаунте, ожидаемое/фактическое поведение. Не выгружайте чужие данные и не выполняйте разрушительную проверку production.

## Для разработчика

- Секреты/дампы только вне Git; клиенту не выдаются service_role/DB credentials.
- Изменения прав БД и сессий проверяются negative tests, не только happy path.
- Перед выпуском: `npm run build:verified`, CI replay миграций и HTTP smoke.
- Известные риски и порядок работ: [операционный план](docs/SECURITY_OPERATIONS.md).
