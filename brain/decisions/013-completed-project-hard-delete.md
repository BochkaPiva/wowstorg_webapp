# ADR 013: Безвозвратное удаление завершённых проектов

Дата: 2026-09-07  
Статус: принято

## Контекст

Архив скрывает завершённые проекты из основной работы, но не позволяет удалить тестовые и ошибочно созданные данные. Администратору нужен единый инструмент очистки заявок и проектов.

## Решение

- Hard delete проекта доступен только роли `WOWSTORG` в служебном разделе очистки.
- Сервер принимает к удалению только проекты со статусом `COMPLETED` и повторно проверяет статус внутри транзакции непосредственно перед удалением.
- Связанные `Order`, `WorkTask` и исходная независимая смета не удаляются: их ссылки на проект обнуляются для сохранения операционной истории.
- Чисто проектные данные удаляются каскадно. Дерево `ProjectFolder` предварительно разрывается из-за `onDelete: Restrict` у самоссылки.
- Ключи файлов считываются внутри транзакции, записи удаляются вместе с проектом, а объекты Storage очищаются best-effort после успешной фиксации БД.
- UI всегда показывает предпросмотр зависимостей и требует явного ввода `DELETE`.

## Последствия

Активный, отменённый или сменивший статус проект удалить через этот API нельзя. Ошибка очистки Storage не откатывает уже подтверждённое удаление из БД и может оставить только внешний объект без доступной метазаписи.
