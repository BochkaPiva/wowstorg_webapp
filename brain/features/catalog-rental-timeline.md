# Временная шкала аренды в каталоге

Реализовано 15.10.2026. После локальной проверки владелец разрешил выпуск в `master`.

## Поведение

- `CatalogSchedule` заменяет прежний блок дат: подготовить к, начало и окончание аренды видны одновременно у Grinvich и Wowstorg.
- Фон шкалы прокручивается мышью, трекпадом, touch и стрелками. Прокрутка не меняет заказ. Окно виртуализировано до 121 дня.
- Три маркера переносятся независимо с ограничениями `minDate ≤ подготовка ≤ начало ≤ окончание`. Перенос показывает предварительные даты и сумму оплачиваемых дней; запись происходит один раз при отпускании. Escape, отмена pointer и потеря фокуса окна отменяют перенос.
- Доступны клавиатурные стрелки и точные поля с календарями. Календарь следует за видимым полем при прокрутке страницы; инерция шкалы не закрывает его.
- «Утром / Вечером» выбираются напрямую. Формула общая, из `rental-days.ts`; один календарный день остаётся полным, подготовка не увеличивает срок оплаты.
- Явная дата подготовки передаётся в корзину без автоматической подмены. Для старого состояния без даты сохранён прежний складской fallback.
- Демо-подбор без дат и дополнение к заявке с унаследованными датами не получают редактируемую шкалу. Существующие scope проекта и корзины не меняются.

## Код и проверки

`src/app/catalog/{CatalogSchedule.tsx,use-catalog-timeline.ts,timeline-dates.ts,CatalogDayPartSwitch.tsx,CatalogDateField.tsx}`. Локальные стили — `header.module.css` и `schedule.module.css`; карточки реквизита и глобальный AppShell вне области редизайна.

Vitest: `catalog-schedule`, `catalog-timeline-dates`, `catalog-cart-lifecycle`. Браузерный сценарий `scripts/quality/catalog-header-browser-check.mjs` запускается против локальной production-сборки, все API подменены синтетическими данными, без записи в БД. Покрывает роли, проекты, демо, дополнения, десктоп и телефон, перенос/отмену/скролл/календарь/корзину. Это не проверка реального оформления заявки в БД.

Новых API, миграций, env и изменений цен нет. Период и части суток остаются в существующем `catalogDates`/localStorage-контракте.
