# Рейтинг и лояльность Greenwich

## Цель

Сделать рейтинг Greenwich восстанавливаемой репутацией сотрудника и единым источником его каталожной скидки. Рейтинг должен поощрять своевременную реакцию и аккуратный возврат, но не превращать единичную ошибку в пожизненное наказание.

## Модель

- Базовый рейтинг — `100`, итог всегда ограничен диапазоном `0…100`.
- Исторические штрафы заявки (просрочка возврата, состояние реквизита) и новые события рейтинга суммируются раздельно.
- Восстанавливаемые отрицательные события после настраиваемой паузы линейно сходят к нулю.
- Ручная корректировка администратора записывается отдельным событием и не выключает автоматический расчёт.
- Уровень выбирается по максимальному `minScore`, который достиг сотрудник; скидка каталога берётся из этого уровня.

## События и справедливые ограничения

- Ответ на контрольное подтверждение заявки: небольшой настраиваемый плюс.
- Пропуск второго и финального касания: отдельные небольшие восстанавливаемые штрафы.
- Возврат после дедлайна: штраф за день с общим потолком.
- Полностью исправный возврат: настраиваемый плюс.
- Ремонт и потеря: разные веса за единицу, расходники не учитываются, действует общий потолок инцидента.

По умолчанию уровни: `Старт 10%` с 0, `Стабильный 20%` с 60, `Надёжный 25%` с 75, `Премиум 30%` с 90. Пороги, названия и скидки редактируются складом в центре Telegram.

## Затронуто

- Prisma: `GreenwichRatingPolicy`, `GreenwichRatingTier`, `GreenwichRatingEvent`.
- Расчёт: `src/server/ratings/greenwich-rating.ts`.
- Каталог и заказ: API каталога, связанные позиции, корзина и `create-order`.
- UI: дашборд Greenwich, корзина, `Администрирование → Telegram`.

## Инварианты

- Сервер повторно вычисляет скидку при загрузке цен и при создании заявки; значение с клиента не считается доверенным.
- В уже созданной заявке сохраняется ценовой снимок, последующее изменение рейтинга не переписывает историю.
- Уровни должны иметь разные пороги; минимальный порог `0` обязателен.
- Скидка ограничена диапазоном `0…100%`.

## Приёмка

- [x] Склад управляет весами, восстановлением и уровнями скидок.
- [x] Каталог, рекомендации, корзина и создание заявки используют один рейтинг и один уровень.
- [x] Greenwich видит текущий уровень, скидку и путь до следующего уровня.
- [x] Ручная корректировка не отключает дальнейшую автоматику.
- [x] Просрочка и инциденты имеют потолки, расходники не штрафуют рейтинг.
