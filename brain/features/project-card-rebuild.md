# Пересборка карточки проекта

## Обновление 14.10.2026

- В новом проекте смета — первый обязательный модуль; конструктор КП необязателен. Ранее подключённые конструкторы и явно сохранённые размеры не скрываются автоматически.
- Заявки по умолчанию занимают 12 колонок; сворачивание сохраняет выбранную ширину, вместо принудительных 4 колонок.
- Цены реальной заявки редактируются в смете как её индивидуальные тарифы, не как цены каталога. Preview использует общую формулу скидок/налогов; сохранение через `warehouse-edit`, WOWSTORG, Serializable, `expectedUpdatedAt`, reserve/status/archive guards. Изменённые клиентские условия Grinvich проходят повторное согласование. Закрытые и выданные заявки не разблокируются.
- Перемещение/удаление/переход связанной заявки — в «⋯»; сохранение появляется только после правки. Примечание склада действительно сохраняется, а индивидуальный тариф больше не сбрасывается при изменении количества.
- Разделы сметы перетаскиваются за шапку или название без отдельной кнопки из шести точек: native drag как на доске задач, preview только шапки, линия до/после целевого раздела. Клик сохраняет сворачивание/переименование; поля и действия не начинают перенос. Alt+↑/↓ переставляет сфокусированную шапку. Escape, отпускание вне сметы, dragend и потеря фокуса убирают временную подсветку; блокировка release-click сбрасывается до следующей клавиатурной активации. Состояние раскрытия и финансовые значения не меняются при перестановке; demo-раздел и read-only остаются защищены. Приёмка: 15 lifecycle-тестов и `project-card-browser-check.mjs --header-drag` на 1440/2048/390 (mouse/keyboard, перехваченные API; не тест phone touch-drag).
- Подрядчики: компактные категории, последняя договорённость и внутренний журнал общения. Подробнее [`project-contractors.md`](./project-contractors.md), ADR 017.
- Контекст/блокеры/заголовок не сбрасываются фоновым обновлением соседнего блока. Обновление подрядчиков не перезагружает смету. Вложенные слои проекта ограничены stacking context ниже app-topbar; fullscreen-порталы сохраняют отдельный слой и прокрутку.

Приёмка: `project-card-browser-check.mjs` (перехваченные API, 1440/2048/390) + реальная HTTP/Prisma/Postgres цепочка в `http-smoke.mjs`; unit route/domain/pricing checks, build:verified, production migration/access checks. Данные скриншотов обозначены QA, не являются реальными итогами бизнеса.

## Цель

Сделать карточку проекта рабочим центром: быстро видно состояние проекта, чей ход, блокеры, задачи, заявки реквизита и финансовую картину без дублирования полей и лишних переходов.

## Границы

- В первой волне не меняем бизнес-модель проектов и смет без отдельного решения.
- Не создаём отдельную систему проектных задач: используем существующие `WorkTask` с `projectId`.
- Не удаляем степпер заявок реквизита.
- Не меняем формулы сметы и XLSX/PDF-контракты при визуальном редизайне.

## Затронуто

- Prisma: без обязательной миграции; используются существующие `Project`, `Order.projectId`, `WorkTask.projectId`, `WorkTask.orderId`.
- API: `/api/projects/[id]`, `/api/tasks/boards/[id]`, `/api/tasks/**`.
- UI: `/projects/[id]`, `/tasks`, `ProjectEstimatePanel`.
- Документация: подробный план в `docs/PROJECT_CARD_REBUILD_PLAN.md`.

## Инварианты

- Архивный проект остаётся read-only.
- Задачи закрытого/архивного проекта не должны шуметь в основной доске, но не удаляются.
- Проектный YouGile и основной YouGile показывают одни и те же задачи через разные фильтры.
- Заявки реквизита остаются связанными с `Order`, а сметные блоки реквизита остаются 1:1 к заявкам.
- Сметная математика, комиссия и налог не меняются в рамках UI-пересборки.

## Приёмка

- [ ] В шапке редактируются название, даты, статус и мяч.
- [ ] Блок "Карточка проекта" как дубль шапки удалён.
- [ ] Статус меняется через рекомендуемое следующее действие и сгруппированное меню.
- [ ] Мяч меняется через компактный сегментированный контроль.
- [ ] Рабочие заметки компактны и не занимают большой пустой блок.
- [ ] В проекте есть блок задач, показывающий задачи с `projectId` текущего проекта.
- [ ] Задачи синхронно видны в проекте и основном YouGile.
- [ ] Задачи закрытых/архивных проектов скрыты из основной доски по умолчанию.
- [ ] Степпер заявок реквизита сохранён.
- [ ] Финансовые итоги сметы сгруппированы по смыслу: клиент, внутреннее, маржа.
