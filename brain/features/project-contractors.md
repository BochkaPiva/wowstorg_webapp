# Подрядчики проекта

Каталог → КП → реальный состав проекта — три отдельные сущности. В карточке проекта появился настраиваемый блок «Подрядчики проекта», доступный также на весь экран. Добавление из каталога или вручную; явный перенос основных подрядчиков выбранного варианта КП; обязанности, контакт, статус, прибытие, договорённости и связь с сохранённым пунктом тайминга. Имена показываются в тайминге; отменённые исключаются.

Контакт копируется на момент добавления. Одного подрядчика не дублируем; повторный перенос не переписывает соглашения и не возвращает отменённых. Цены остаются в КП/смете. По умолчанию участник на согласовании, не «забронирован». Подробнее: ADR 017.

API: `GET/POST /api/projects/[id]/contractors`, `PATCH /api/projects/[id]/contractors/[assignmentId]`. Zod, WOWSTORG, Serializable, revision CAS, archive guard и activity log.

Перед первым production нужен `docs/sql/deploy_project_contractors.sql`, затем `docs/sql/deploy_project_contractor_categories.sql` после backup и до публикации нового клиента. Второй файл повторно запускаем: уже заполненные/вручную очищенные категории он не перезаписывает. Не запускать все старые pending migrations автоматически: ранее зафиксирован drift журнала. При отсутствии таблицы/колонки блок показывает сообщение о миграции. Production DB и живой импорт проверяются отдельно после применения.

Расширение 09.10.2026: команда группируется по первой категории участия, остальные видны тегами; один подрядчик не дублируется. Категории редактируются отдельно от обязанностей. Перенос из КП использует реальную категорию услуги, а не случайное название раздела. Поиск и фильтры сокращают список. Статус меняется прямо в строке; удаление из активной команды с коротким подтверждением переводит участие в CANCELLED, сохраняет договорённости и позволяет восстановить. Редактирование открывается в контекстной панели с собственной прокруткой и защитой черновика/revision-конфликта.

«На доску» из строки открывает проектную доску и добавляет ссылку на участие (не на карточку каталога). На доске доступны просмотр обязанностей, контакты, тайминг, договорённости и та же форма редактирования. Изменения обновляют живую карточку; удаление карточки с доски не меняет состав команды. Подробнее: `project-workspace-v2.md`, ADR 012/017.

Backlog PDF/PPTX: переполнение текста, иерархия заголовков и основного текста. В этой итерации генератор не меняется; отдельный приоритет после каталога и состава проекта.

Проверка расширения: 53 файла / 312 тестов, Prisma validate; browser QA 1440/390/2048 на изолированных API-ответах. Категории, поиск, прямой статус, отмена/восстановление, contextual editor, dirty guard/CAS, добавление на доску, все восемь типов сущностей, защита повторного добавления, правка участия на доске, вложенный Escape, переход в тайминг и возврат, архив read-only; ноль ошибок браузера. Серверные route-тесты проверяют scope ссылок, чужие доски, архив, auth, idempotency и допустимое перемещение осиротевшей карточки без возможности подмены ссылки. Независимая визуальная проверка `impeccable`: ship. Живое применение SQL, storage и реальные записи не проверены до согласованного rollout.
