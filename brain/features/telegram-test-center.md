# Центр проверки Telegram-бота

## Цель

Дать складу единое безопасное место для проверки настроек Telegram, маршрутов доставки, шаблонов уведомлений и inline-кнопок без создания или изменения реальных заявок, проектов и задач.

## Границы

- Центр не запускает фоновые cron-задачи и не подменяет их расписание.
- Тестовые callback-кнопки не меняют статусы, резерв, сметы или другие данные.
- Массовая проверка Greenwich запускается только вручную и требует подтверждения в интерфейсе.

## Затронуто

- UI: `src/app/admin/telegram/page.tsx`
- API: `GET/POST /api/admin/telegram`
- Webhook: `POST /api/telegram/webhook`
- Сценарии: `src/server/telegram-test-scenarios.ts`

## Инварианты

- Все тестовые сообщения имеют явную маркировку `ТЕСТ`.
- Callback data тестовых кнопок начинается с `tgtest:` и обрабатывается до бизнес-callback обработчиков.
- Получатель всегда выбирается явно: склад, конкретный Greenwich, произвольный Chat ID или подтверждённая массовая отправка.
- Ответ Telegram API отображается в истории текущей браузерной сессии.
