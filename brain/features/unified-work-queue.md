# Единая рабочая очередь

## Цель

Один экран для проектов, самостоятельных заявок и независимых смет с фильтрами, предпросмотром и безопасными быстрыми действиями.

## Доменные границы

- `Project` — полноценная клиентская работа: контакты, задачи, файлы, даты, сметы и связанные заявки.
- `Order` — резерв, склад, выдача, приёмка и состояние реквизита.
- `StandaloneEstimate` — расчёт до появления проекта: только метаданные и смета.
- В независимую смету можно добавлять позиции из demo-каталога. Они сохраняются как связанные с `Item` строки сметы, участвуют в итогах, но не создают складской резерв до превращения расчёта в реальную работу.
- `WorkQueueItem` — производная read-model, а не таблица и не источник доменного статуса.

## Независимая смета

- `POST /api/standalone-estimates` создаёт сущность и первую `ProjectEstimateVersion`.
- `/estimates/[id]` открывает только сметный редактор и экспорт.
- Заказчик необязателен до преобразования.
- `POST /api/standalone-estimates/[id]/convert` создаёт `Project(mode=FULL)` и переносит версии сметы в `Serializable`-транзакции.
- После преобразования независимая смета доступна только для перехода в созданный проект.
- До преобразования независимую смету можно удалить из рабочей очереди после явного подтверждения; её версии, разделы и строки удаляются каскадно.
- Преобразованную в проект смету удалить нельзя: она остаётся источником истории преобразования.
- До преобразования смета не учитывается как финансовый факт.

## Быстрый запуск работы — 11.10.2026

- Шапка `/work` запускает самостоятельное КП, независимую смету или проект через существующие авторизованные API. Создание заявок остаётся в каталоге реквизита.
- КП и смета требуют только название; заказчик необязателен. Проект требует заказчика. Совпавшее название связывается с существующим ID; новое название в КП/смете сохраняется как контекст лида.
- Форма использует native dialog, фокус на названии и доступный combobox. Escape сначала закрывает подсказки заказчиков, затем форму. Повторная отправка заблокирована на время запроса; автоматического повтора создания нет.
- После создания открывается соответствующий редактор с безопасным возвратом в рабочую очередь. При неопределённом результате предлагается проверить список перед повтором.
- Read-model очереди, финансовые итоги, резерв склада и преобразование сметы не изменены. Новых API, env и миграций нет.

## Инварианты очереди

Уточнение интерфейса от 12.10.2026: поиск, компактные native selectors типа/фазы/сортировки и bookmark «Сохранить текущий вид» собраны в одну полноширинную полосу с целями 44px и переносом на телефоне. Условные даты, сохранённые виды и архивные настройки сохранены. Возврат страницы теперь принадлежит AppShell: одна спокойная стрелка с названием фактического назначения над содержимым; безопасный контекст возврата детальных страниц сохраняется. Новых API, env и миграций нет. Границы проверки: [compact-work-verification.md](../../.impeccable/review/compact-work-verification.md).

- Проект со связанными заявками — одна карточка, заявки показаны дочерними степперами.
- Проект без заявок не получает искусственный степпер.
- Самостоятельная заявка — отдельная карточка.
- Независимая смета — отдельная карточка без проектного статуса и степпера.
- Архивирование не подменяет бизнес-статус.
- Цвет кодирует только состояние или требуемое действие.

## Приёмка

- [x] Очередь фильтруется по периоду, типу, фазе, датам и поиску.
- [x] Карточки разворачиваются без перехода на детальную страницу.
- [x] Статус проекта меняется из очереди через существующие доменные правила.
- [x] «Составить смету» создаёт `StandaloneEstimate` и сразу открывает редактор.
- [x] Редактор независимой сметы не показывает проектные контакты, задачи, даты и файлы.
- [x] Из редактора независимой сметы можно найти реквизит в demo-каталоге, указать количество и дни и добавить его в расчёт без резерва склада.
- [x] Смету можно преобразовать в проект без потери строк и финансовых настроек.
- [x] Независимую смету можно удалить быстрым действием из очереди с подтверждением.
- [x] У заказчика можно загрузить, заменить и удалить логотип.
