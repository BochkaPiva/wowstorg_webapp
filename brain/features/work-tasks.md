# Задачи / рабочая доска

## Цель
Встроить в Wowstorg локальную рабочую доску в стиле YouGile: быстрые карточки, колонки, полноценные подзадачи, исполнители, дедлайны, напоминания и рабочий журнал без внешней синхронизации.

## Границы
- Не интегрируем YouGile API в MVP.
- Не делаем двустороннюю синхронизацию с внешними досками.
- Не заменяем статусы проектов и заявок задачами: задачи дополняют операционную картину.

## Затронуто
- Prisma: `WorkTaskBoard`, `WorkTaskColumn`, `WorkTask`, `WorkTaskChecklistItem`, `WorkTaskAssignee`, `WorkTaskChecklistAssignee`, `WorkTaskActivity`, `WorkTaskPriority`, `WorkTaskActivityKind`.
- API: `/api/tasks/**`.
- UI: `/tasks`, блок «Мои задачи» на главной.
- Связи: задачи могут ссылаться на `Project`, `Order`, `User`.

## Инварианты
- Задачи доступны только `WOWSTORG` в первом срезе.
- Дедлайны хранятся как date-only через UTC midnight, по текущему паттерну проекта.
- Завершённые задачи скрываются с основной доски и из «Моих задач».
- Архив задач — отдельное мягкое состояние `WorkTask.archivedAt`: архивные задачи не видны на доске, в дашборде, напоминаниях и «Моих задачах», но доступны из скрытого архива доски.
- Нельзя удалить колонку, пока в ней есть задачи.
- Журнал задачи append-only: пользовательские заметки и системные события не перезаписывают друг друга.
- Подзадачи образуют рекурсивное дерево через `WorkTaskChecklistItem.parentId`; удаление узла каскадно удаляет только его дочернюю ветку.
- Напоминание задачи или подзадачи отправляется один раз для конкретного выбранного времени; повторное редактирование времени создаёт новый ключ доставки.
- Стикер может быть прикреплён до выбора конкретного значения; состояние прикрепления хранится отдельно от значения приоритета, даты, напоминания и исполнителя.
- Задача и подзадача поддерживают нескольких исполнителей через отдельные таблицы связей. Устаревшее поле `assigneeUserId` хранит первого исполнителя только для совместимости со старыми выборками во время перехода.
- Дедлайн поддерживает дату начала, дату завершения и необязательное точное время.
- Напоминание поддерживает собственный текст. Если выбрана только дата, уведомление планируется на 13:00 по Омску; если выбрано время, используется оно.
- Клиент синхронизирует доску каждые 12 секунд и при возврате во вкладку, но не подменяет состояние во время перетаскивания, редактирования или незавершённой мутации.

## Приёмка
- [x] Есть рабочая доска с колонками.
- [x] Можно добавлять, редактировать и удалять пустые колонки.
- [x] Можно добавлять, редактировать, перемещать и удалять задачи.
- [x] У задачи есть один или несколько исполнителей, дедлайн, приоритет, цвет, проект, заявка.
- [x] У задачи есть рекурсивное дерево подзадач без ограничения интерфейса одним уровнем.
- [x] Подзадача имеет одного или нескольких исполнителей, дедлайн, приоритет, цвет и напоминание; описание не занимает место в рабочей карточке.
- [x] Быстрые hover-действия позволяют назначить исполнителя и добавить/изменить стикеры без открытия большой формы.
- [x] Стикеры приоритета, дедлайна, напоминания и исполнителя кликабельны напрямую и открывают свой компактный редактор, не открывая журнал задачи.
- [x] У каждого узла дерева есть однокликовое добавление вложенной подзадачи; корневые и вложенные уровни соединены видимыми ветвями.
- [x] Меню карточки поддерживает перенос, завершение, архив, дублирование, цвет и удаление.
- [x] В боковой панели задачи доступны история изменений, рабочие заметки и расширенное управление подзадачами.
- [x] На карточке виден индикатор сохранённых заметок.
- [x] Перетаскивание показывает пунктирный placeholder реального размера карточки и сохраняется оптимистично без полной перезагрузки доски.
- [x] Быстрые последовательные изменения одной задачи отправляются в сервер по очереди; разные задачи сохраняются параллельно.
- [x] Доска фоново синхронизируется между устройствами.
- [x] Колонки не имеют внутренних вертикальных скроллов: высота страницы определяется содержимым, а сетка переносит колонки без горизонтального скролла.
- [x] Светлая тема используется по умолчанию, тёмная доступна через сохраняемый переключатель.
- [x] Выбранное напоминание задачи или подзадачи обрабатывается reminder runner каждые 15 минут.
- [x] На главной отображаются задачи текущего сотрудника.
- [x] Колонка завершения умеет архивировать выполненные задачи без удаления.
