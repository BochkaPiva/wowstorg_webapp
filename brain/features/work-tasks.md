# Задачи / рабочая доска

## Цель
Встроить в Wowstorg локальную рабочую доску в стиле YouGile: быстрые карточки, колонки, полноценные подзадачи, исполнители, дедлайны, напоминания и рабочий журнал без внешней синхронизации.

## Границы
- Не интегрируем YouGile API в MVP.
- Не делаем двустороннюю синхронизацию с внешними досками.
- Не заменяем статусы проектов и заявок задачами: задачи дополняют операционную картину.

## Затронуто
- Prisma: `WorkTaskBoard`, `WorkTaskColumn`, `WorkTask`, `WorkTaskChecklistItem`, `WorkTaskActivity`, `WorkTaskPriority`, `WorkTaskActivityKind`.
- API: `/api/tasks/**`.
- UI: `/tasks`, блок «Мои задачи» на главной.
- Связи: задачи могут ссылаться на `Project`, `Order`, `User`.

## Инварианты
- Задачи доступны только `WOWSTORG` в первом срезе.
- Дедлайны хранятся как date-only через UTC midnight, по текущему паттерну проекта.
- Завершённые задачи скрываются с основной доски и из «Моих задач».
- Архив задач — отдельное мягкое состояние `WorkTask.archivedAt`: архивные задачи не видны на доске, в дашборде, напоминаниях и «Моих задачах», но доступны из скрытого архива доски.
- Нельзя удалить колонку, пока в ней есть задачи.
- Журнал задачи append-only: пользовательские заметки и системные события не перезаписывают друг друга.
- Напоминание задачи или подзадачи отправляется один раз для конкретного выбранного времени; повторное редактирование времени создаёт новый ключ доставки.
- Клиент синхронизирует доску каждые 12 секунд и при возврате во вкладку, но не подменяет состояние во время перетаскивания, редактирования или незавершённой мутации.
