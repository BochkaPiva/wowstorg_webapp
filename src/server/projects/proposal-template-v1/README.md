# Фирменный адаптер КП v1

`source.pptx` — неизменённый пользовательский `МАКЕТ.pptx`, 13 слайдов, 1280×720 (16:9).
SHA256: `79E0F3BA7386D308E383EDEA0C96EED9F8CA0334254BCE566B89BD0EE3455754`.

JPEG-фоны получены из исходных слайдов 2, 5 и 7 через artifact-tool, sharp JPEG quality 88/mozjpeg. Происхождение встроено в JPEG COM. В текущем плане используются 2 и 7; исходный слайд 5 сохранён для возможной портретной композиции. Это исходная графика пользователя, не AI-генерация. PDF использует компактные фоновые изображения; PPTX сохраняет исходные рисунки, layouts/master/theme и добавляет редактируемый текст и фото.

`OksFree.otf` — точная копия предоставленного `Oks Free 0013.otf`.
SHA256: `FB472A3FADA48A745A8A3291E4BA029DD7C23376ED40EEBB733A9CA348CD82C3`.
Имя семейства — `Oks Free`, один вес. Искусственный bold не применяется.

Это OpenType/CFF (`OTTO`). PDF встраивает полный шрифт с правильным `/OpenType` subtype; сокращённый CFF subset не используется из-за некорректного результата текущего pdf-lib/fontkit. Внутренние флаги OS/2 разрешают preview/print embedding, но не editable embedding. В PPTX шрифт поэтому не встраивается: он назначен нативным текстовым блокам, на компьютере получателя нужен установленный Oks Free. Эти технические флаги не являются подтверждением лицензии или прав на распространение. Происхождение — файл, переданный владельцем продукта.

Знак среднего пункта и неразрывные пробелы заменяются безопасными разделителем/пробелами, отсутствующими в данном шрифте. Текст разбивается на страницы по измерениям Oks Free; фотографии вписываются целиком без обрезки. Рендерер и assets привязаны к `wowstorg-template-v1`: при замене макета/шрифта нужен новый adapter ID для воспроизводимости старых снимков.

Следующий этап: проверка в настольном PowerPoint, Google Slides и LibreOffice, альтернативная более плотная композиция нескольких услуг, очередь долговечных фоновых заданий и интерфейс истории экспорта. Текущие тесты структуры PPTX/artifact-tool и PDF/Poppler не заменяют проверки в этих приложениях.
